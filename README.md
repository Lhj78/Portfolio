# Laxmi Ahirwar – Portfolio

Hi, I'm Laxmi. This is my personal portfolio website, where I show the things I've built and what I've learned along the way.

I'm a B.Tech student in Computer Science Engineering (Data Science & AI) at Apeejay Stya University, graduating in 2027. I like building machine learning models and then turning them into real, usable products.

## What's on the site

- **About:** a short intro to who I am and what I care about
- **Skills:** the languages, ML tools, web frameworks and platforms I work with
- **Experience:** my internships at the Delhi Secretariat and NIT Delhi
- **Projects:** the work I'm proudest of, plus smaller experiments
- **Certifications:** hackathons, workshops and courses
- **Contact:** the best ways to reach me

## Projects I'm proudest of

**Prenatal Nutrition AI**
A tool that helps rural healthcare workers in India assess fetal nutrition. It combines a tabular model on clinical and dietary data with a ResNet-50 model for ultrasound images, and it reached an AUC-ROC of 0.976.

**AAS – Auto Appeal System**
A government service platform built with Django REST Framework and React. It has seven user roles, a dual-officer backup workflow and automatic escalation for late applications.

## How it's built

The whole site is one HTML file with the CSS and JavaScript inside. There are no frameworks and nothing to install. It uses Google Fonts (Bricolage Grotesque and Newsreader), supports light and dark mode, and works on phones.

## Running it locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

That's it.

## Deploying it

You can host it for free on GitHub Pages, Netlify or Vercel. With GitHub Pages, go to **Settings → Pages**, choose your main branch, and your site will go live in a minute or two.

## Making it your own

If you'd like to use this as a starting point, search the file for my details (name, email, projects) and swap in yours. The colors and fonts are defined at the top of the stylesheet as variables, so changing the look takes only a few edits.
